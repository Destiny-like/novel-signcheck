# 签约自查清单（执行版）

供 SKILL.md Step 5 调用。逐项打勾，任一 blocking 未通过 → 结论不得为"通过"。

## 通用项（所有平台）

- [ ] (blocking) 待查文本完整，无截断、无"TODO/占位符/未完待续"式占位
- [ ] (blocking) 违禁词扫描通过（涉政/涉黄/涉暴/敏感词）
- [ ] (blocking) AI 味检测 ≥40/50，或"存疑"项已逐条给出修改方向
- [ ] (advisory) 简介：有钩子、有卖点、有悬念，无红线词
- [ ] (advisory) 书名：题材关键词直给，不文艺腔

## 番茄小说

- [ ] (blocking) 签约资格：Lv.2+ 走连载（≥2 万字）；Lv.0/1 须已完本 15–30 万字（按分类）且申请机会未用尽
- [ ] (blocking) AI 粗制滥造三特征复核：行文机械□ 语言模板化□ 空洞水文□（任一命中即不通过）
- [ ] (blocking) 低龄读者红线：无早恋美化/校园暴力/不良价值观导向
- [ ] (advisory) 开篇 3 章：300 字内出钩子，爽点密度≥1 个/章
- [ ] (advisory) 章节体量：单章 2000–3000 字，短平快
- [ ] 投稿材料包：简介□ 大纲□ 联系方式□（完本签约需确认全书字数达标□）

## 七猫小说

- [ ] (blocking) 正文 ≥2 万字；大纲完备（梗概+分卷/分章细纲+人物小传）
- [ ] (blocking) 开篇三章钩子强度：编辑初审视角，第一章 1000 字内必须出现核心冲突或强悬念
- [ ] (blocking) AI 味检测通过（开篇部分单独加权：开篇 <35 分即不通过）
- [ ] (blocking) 题材调性匹配：女频是否新媒体爽文感；男频是否在收稿品类内
- [ ] (advisory) 人物小传：主角有明确欲望与困境，配角有辨识度
- [ ] 投稿材料包：正文□ 大纲□ 人物小传□ 申请表□ 联系方式□（注明目标编辑/投稿邮箱□）

## 起点中文网

- [ ] (blocking) 签约资格三选一：正文满 6000 字（编辑初审）/ 累计 10 万字（自主申请）/ 邮箱投稿 2 万字开篇+大纲
- [ ] (blocking) AI 水文检查：信息密度（删掉修饰后是否还有实质内容）、D5 重复铺陈≥3 处即高风险、模板化灌水章节
- [ ] (blocking) "文学本身"检查：核心创意/人物/情节出自作者本人，AI 仅做辅助环节（建议主动说明 AI 使用范围）
- [ ] (advisory) 追读指标：章末钩子密度、悬念设置（起点拼追读不拼完读）
- [ ] (advisory) 题材：是否在男频核心品类内（玄幻/仙侠/都市/历史/轻小说）
- [ ] 投稿材料包：书名□ 开篇正文□ 大纲□ 联系方式□

## 结论判定

- 全部 blocking 通过 → **通过**（可投稿）
- 有 blocking 未通过但可改 → **有条件通过**（列出必改项）
- 资格类 blocking 未通过（如番茄申请机会用尽）→ **不通过**（给返工路径）
