# 签约前自查 Skill（signcheck-novel-zh）v0.2

网文投稿前的"模拟考"：输入正文 + 目标平台，输出"通过 / 有条件通过 / 不通过"结论与逐条修改建议。

**差异化**：市面上的 AI 写作工具都在解决"怎么写"，这个 skill 解决"怎么过审签约"——覆盖**分平台** AI 味检测、内容合规红线扫描、分平台签约资格检查。三平台 AI 口径不同，分别检测：番茄签约前拒签"AI 粗制滥造"（最严）、七猫人工编辑看开篇（开篇加权）、起点 AI 水文治理（查信息密度与灌水）。

## 当前支持

- 番茄小说（策略卡 v2026.10.12：Lv.0/1 完本签约新规、AI 粗制滥造拒签红线）
- 七猫小说（策略卡 v2026.10.16：2 万字+大纲内投、千字 6 元全勤）
- 起点中文网（策略卡 v2026.10.16：6000 字初审/10 万字自助申请/"文学本身不能是AI"+水文治理）
- 知乎盐选：v0.3 补齐

## 文件结构

```
signcheck-skill/
├── SKILL.md                  # skill 主文件（Anthropic Agent Skills 规范，兼容 OpenWrite 广场）
├── references/
│   ├── platform-fanqie.md   # 番茄平台策略卡（带 policy_version + effective_date）
│   ├── platform-qimao.md     # 七猫平台策略卡
│   ├── platform-qidian.md    # 起点平台策略卡
│   └── checklist.md          # 分平台签约自查清单（执行版）
└── scripts/
    └── ai_feel_check.py      # AI 味 + 平台口径检测 v0.2（零依赖，本地运行）
```

## 用法

1. **在 Agent 中**：把本目录放进 skill 目录（如 `~/.agents/skills/signcheck-novel-zh`），对 AI 说"用签约前自查 skill 检查这篇稿子，目标平台番茄"。
2. **单独跑机械检测**：`python3 scripts/ai_feel_check.py 你的正文.txt --platform fanqie|qimao|qidian`

## 检测机制（v0.2）

- 机械指标：逗号÷句号比（台词层/叙述层分离）、句长标准差、**分句长度**（逗号÷句号的盲区补充）
- 可计算信号：A1 情绪直述 / A4 段尾升华 / B2 程度副词 / B3 比喻滥用 / B5 宏大意象 / C2 排比三连 / C3 对称句式 / C6 逗号碎句 / D5 重复铺陈 / E2 说明文腔 / F 中文 AI 高频词
- 分平台配置：不同的信号密度阈值 + 不同的检测重点 + 起点水文专项（重复铺陈≥3 处高风险）
- 设计吸收自 `zh-novel-writing-toolkit/ai-detector-zh`（MIT）：五维 50 分制、A–F 信号表、"网文套路≠AI味"边界声明

## 政策时效声明

平台规则变化快（如番茄 2026-10-12 签约新规、阅文 2026-10-16 创作大会 AI 表态）。策略卡带版本号与生效日期，过期 >90 天 skill 会先警告。欢迎提 issue 更新政策。
